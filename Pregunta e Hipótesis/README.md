## Introducción

El rendimiento académico puede verse influenciado por distintos factores, entre ellos el género y el tipo de evaluación aplicada. Analizar las diferencias en las calificaciones permite comprender si existen variaciones significativas en el desempeño de los estudiantes y cómo estas pueden relacionarse con las características de cada examen. En este estudio se evaluará si existen diferencias en las notas promedio entre hombres y mujeres, así como posibles variaciones en el rendimiento académico entre distintos exámenes aplicados durante el período académico.

## PREGUNTA DE INVESTIGACIÓN 

1. ¿Existen diferencias entre las notas promedio de examenes entre género? 
2. ¿Hay alguna diferencia en el rendimiento académico al realizar diferentes exámenes?

## HIPÓTESIS

1.
Hipótesis nula (H0)
No hay diferencias significativas entre hombres y mujeres en las notas promedio.

Hipótesis alternativa (H1)
Existen diferencias significativas entre hombres y mujeres en las notas promedio.

2. 
Hipótesis nula (H0)
El promedio de notas es igual entre ambos exámenes comparados.

Hipótesis alternativa (H1)
El promedio de notas difiere entre ambos exámenes comparados.
